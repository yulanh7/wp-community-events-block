Event listings and registrations for churches, community groups and nonprofits, built with Gutenberg blocks.

== Description ==

A WordPress block plugin that displays the next upcoming event with its date, time and location.

== Installation ==

Activate the plugin through the 'Plugins' screen in WordPress
